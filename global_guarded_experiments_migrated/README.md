# Global Guarded Experiments

This folder collects the experiment entry scripts that call
`global_guarded_core.py` and the generated result files from those runs.

## Layout

- `code/`: experiment scripts and core implementation files.
- `code/k*/global_guarded/`: per-k wrapper scripts.
- `results/dataset_compare/`: dataset comparison outputs.
- `results/k*/global_guarded/`: per-k global guarded outputs.

The original files under `vector_hue/` were left in place.
