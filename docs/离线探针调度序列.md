为避免在线实时计算导致通信速率下降，本文采用离线探针调度策略。首先构建多个等长且满足 BER_legal(S_k) ≤ ε 的探针组合，并离线统计每组探针对各非法位置和各合法链路的误码率 BER_{e,l}(S_k)。随后通过 max-min 优化确定各探针组的最优使用比例或固定调度序列，使整体非法最小安全误码率最大化。在线通信时，系统仅按照预计算序列 H^* 依次选择探针组，无需实时优化计算，从而在保证传输速率的同时提升安全性。

## 离线频率优化 + 风险均衡排序 + 在线查表执行

流程如下：

1. 构建 K 个等长探针组合 S_1, ..., S_K
2. 筛选每组探针，使 BER_legal(S_k) ≤ ε
3. 离线计算每组探针对所有非法位置和合法链路的 BER_{e,l}(S_k)
4. 求最优使用比例 p_k，使整体 min_illegal_BER 最大
5. 根据 p_k 生成长度为 T 的探针序列 H
6. 对 H 做风险均衡排序，避免连续泄露给同一非法位置/合法链路
7. 在线通信时只按 H 的顺序使用探针组

关键目标函数是：

p^*
=
\arg\max_p
\min_{e \in E,\ l \in L}
\min\left(
\sum_{k=1}^{K} p_k BER_{e,l}(S_k),
1 - \sum_{k=1}^{K} p_k BER_{e,l}(S_k)
\right)

在线阶段只需要：

S_t = H^*[t]

或者：

S_t = H^*[(t + offset(key)) \bmod T]
