## 二、原始实验分析（单主成分系统）

### 2.1 原始方法
- **指纹提取**：对每个位置做线性去趋势 → SVD → 取第一右奇异向量 `w` → 投影 `z = residual @ w` → `code = sign(z)`
- **通信方式**：4 个位置同时发送，symbol combination 有 `2^4 = 16` 种
- **hue mapping**：将每种 symbol combination 映射到一个 probe 值
- **解码**：`gamma = code^T @ u`，其中 `u = (Y_obs - mean) @ w`

### 2.2 原始结果（来自 `batch_test_zero_ber_results.csv`）
- 找到 **24 个组合**的 probe sets 实现 **legal BER = 0**（exact evaluation + FEC 验证）
- 但 **所有组合均未评估安全性**

### 2.3 安全性验证（关键发现）

对单主成分 zero-BER probe set `(1, 3, 12, 22)` 进行非法位置攻击测试：

| 非法位置 | 单主成分攻击 secure BER | 多主成分攻击 secure BER |
|---------|----------------------|----------------------|
| Pos 2 | **0.000** | **0.000** |
| Pos 4 | **0.000** | **0.000** |
| Pos 5 | **0.000** | **0.000** |
| Pos 7 | 0.125 | **0.000** |
| Pos 8 | **0.000** | **0.000** |

**结论**：单主成分方案虽然通信可靠性完美（BER=0），但**安全性完全失效**——大量非法位置能完美解码（BER=0）。这是因为所有位置共享同一个 LED 阵列的物理响应模式，SVD 第一主成分方向高度对齐。

## 三、多主成分方案设计与实现

### 3.1 设计动机
既然单主成分的 `code = sign(z_1)` 无法区分位置，直觉是利用第二、第三主成分（PC2、PC3）的附加信息来"放大差异"。

### 3.2 核心修改（`test_4_simple.py`）

#### 3.2.1 指纹模型扩展
```python
@dataclass
class FingerprintModel:
    # 原有字段...
    W: Array = None          # D x k, 多主成分方向矩阵
    Z: Array = None          # P x k, 多主成分投影矩阵
    multi_code: Array = None # P x k, 多主成分code矩阵
    eff_code: Array = None   # P, 有效发送code
    eff_z: Array = None      # P, 有效投影
    eff_w: Array = None      # D, 有效接收方向
```

#### 3.2.2 多主成分提取
```python
N_COMPONENTS = 3
ALPHA = np.array([0.75, 0.20, 0.05])  # 发送端混合权重
BETA = np.array([0.70, 0.25, 0.05])   # 接收端解码权重
```

提取过程：
1. SVD 取前 3 个主成分：`W = Vt[:3].T` (D×3)
2. 投影矩阵：`Z = residual @ W` (P×3)
3. 有效发送方向：`eff_w = W @ ALPHA` (D, 一维)
4. 有效发送 code：`eff_code = sign(Z @ ALPHA)` (P)
5. 方向对齐：用 `eff_code` 做相关性对齐（而非单主成分 `code`）

#### 3.2.3 关键修复历程

| 修复项 | 问题 | 解决方案 |
|--------|------|---------|
| 发送-接收不匹配 | 发送用 `eff_code`，接收用 `multi_code` 多主成分联合解码，导致 Pos 2 与 ref 相关性为 0 | 改为统一使用一维 `eff_w` 和 `eff_code` 解码 |
| hue mapping 不匹配 | `generate_mapping_candidates` 仍用单主成分 `m.z` | 改为使用 `m.eff_z`（多主成分混合投影） |
| 对齐方向错误 | `align_model_directions` 用 `ref.code` 而非 `ref.eff_code` | 改为用 `eff_code` 做方向对齐 |

## 四、幅度感知 Hue Mapping（方案 B）

### 4.1 设计原理
原始 `generate_mapping_candidates` 只要求符号匹配（`sign * z > 0`），但丢弃了幅度信息。幅度感知版本增加约束：

```
gamma_i = sign_i * z_i > threshold
threshold = MIN_GAMMA_RATIO * max(|z|)
```

目标：让每个 symbol combination 对应的 probe 不仅符号匹配，还要保证解码时有足够的信噪比（gamma 幅度）。

### 4.2 实现细节
新增函数 `generate_mapping_candidates_amplitude_aware`：
1. 对每个 probe 计算所有位置的 `gamma_i = sign_i * z_i`
2. 要求所有 `gamma_i > 0` 且 `min(gamma_i / max|z|) >= min_gamma_ratio`
3. 评分标准：`score = min_gamma * 10 + avg_gamma`
4. 如果幅度保证通过的数量不足，降级到仅符号匹配

### 4.3 实验结果

对旧 probe set `(1, 3, 12, 22)` 测试：

| 版本 | Exact Legal BER | FEC Legal BER | Worst Illegal Secure |
|------|----------------|---------------|---------------------|
| 原始版本 | 0.078 | 0.043 | 0.062 |
| 幅度感知 (min_gamma_ratio=0.05) | **0.016** | **0.004** | 0.000 |

**关键发现**：
- 幅度感知将 legal BER **从 0.078 大幅降至 0.016**（接近目标 0.005）
- 但某些非法位置的 secure BER 也降为 0，说明提升 gamma 幅度会同时帮助某些非法位置

## 五、物理层面的根本原因分析

### 5.1 SVD 主成分方向高度共享

对 15 个位置的全矩阵 SVD 分析显示：

**PC1 方向相关性（绝对值）**：
```
Pos 2:  [0.08, 1.00, 0.71, 0.96, 0.98, 0.70, ...]
Pos 4:  [0.30, 0.96, 0.57, 1.00, 0.93, 0.56, ...]
Pos 5:  [0.06, 0.98, 0.82, 0.93, 1.00, 0.81, ...]
Pos 14: [0.19, 0.99, 0.64, 0.99, 0.97, 0.63, ...]
```

大量位置对的 PC1 方向相关性高达 **0.92~0.99**！

**PC2 方向相关性**：
```
Pos 2:  [0.30, 1.00, 0.81, 0.14, 0.97, 0.46, ...]
Pos 5:  [0.43, 0.97, 0.74, 0.12, 1.00, 0.35, ...]
Pos 14: [0.28, 1.00, 0.82, 0.16, 0.96, 0.48, ...]
```

PC2 在某些位置间相关性也达到 **0.97~1.00**！

### 5.2 为什么多主成分无法有效区分位置？

**核心原因**：
> **SVD 提取的主成分方向 W 不是"位置特异性"的，而是"LED 阵列一般响应模式"**
>
> PC1 ≈ 亮度响应曲线  
> PC2 ≈ 色温/角度响应曲线  
> PC3 ≈ 噪声/细微模式

所有位置共享同一个光源，因此它们的主成分方向天然对齐。多主成分混合后：
```
位置 A: eff_w = W_A @ alpha ≈ W_shared @ alpha
位置 B: eff_w = W_B @ alpha ≈ W_shared @ alpha
```
因为 W_A ≈ W_B，所以 eff_w_A ≈ eff_w_B！

**真正区分位置的是投影值 Z，而非方向 W。**

## 八、结论

### 8.1 核心发现

1. **单主成分 4-位置通信虽然 BER=0，但完全不安全**（大量非法位置 BER=0）
2. **多主成分能提升安全性**（illegal secure BER 从 ~0 提升到 ~0.06~0.125），但代价是 legal BER 上升
3. **幅度感知 hue mapping 显著改善通信可靠性**（legal BER 从 0.078 降到 0.016），但无法解决根本安全问题
4. **物理根本限制**：15 个位置的 SVD 主成分方向高度共享（相关性 0.9+），导致任何线性混合都无法创造出独立的区分维度

### 8.2 4-位置方案的理论评估

> **在 15/28 位置白光照条件下，4-位置同时满足 legal BER ≤ 0.005 且 min illegal BER ≥ 0.2 极其困难，甚至可能不可能。**
>
> 原因：
> - 位置间 SVD 主成分方向共享度太高
> - 4 位置叠加产生 16 种 symbol combination，对 probe 区分度要求呈指数增长
> - 任何线性混合（ALPHA）都会同时影响合法和非法位置的解码

### 8.3 可行的务实方案

| 方案 | 位置数 | Legal BER | Security | 可行性 | 建议 |
|------|--------|-----------|----------|--------|------|
| A | 3 | 0.000 | ≥ 0.2 | ✅ 已验证 | **推荐** |
| B | 4 + 单主成分 | 0.000 | ≥ 0.05~0.1 | ⚠️ 通信完美，安全较弱 | 接受理论极限 |
| C | 4 + 多主成分 + 放宽 | ≤ 0.05 (FEC后<0.001) | ≥ 0.1 | ⚠️ 需大量搜索 | 可能可行 |
| D | 4 + 非线性映射 | 未知 | 未知 | ❓ 研究性质 | 长期探索 |

## 九、双探针联合解码实验（Dual-Probe Joint Decoding）

### 9.1 动机
由于 SVD 主成分方向在所有位置间高度共享（相关性 0.9+），单探针系统的安全性完全依赖于探针集合本身的保密性。一旦非法位置知道探针集合，即可构建相同模型并完美解码。

**核心假设**：如果合法收发双方共享**两组不同的探针集合** `P_a`（发送端）和 `P_b`（验证端），并对同一信号做联合判决（仅当两者解码一致时才接受），则非法位置需要同时猜对两组模型才能通过验证，安全 BER 可能提升。

### 9.2 方法
- **发送端**：用 `P_a` 构建指纹模型和 hue mapping，发射信号
- **接收端**：同时用 `P_a` 和 `P_b` 各自独立解码
- **联合判决**：仅当 `P_a` 解码结果 == `P_b` 解码结果 == 真实比特时，才视为正确接收
- **非法位置攻击**：非法位置同样拥有 `P_a` 和 `P_b` 的全部数据，分别建模后做联合判决

### 9.3 关键架构约束
实验中发现严重架构 bug：如果 `P_a` 和 `P_b` 完全不相交，则 `P_b` 接收端在 `observe_block_from_measured_matrix` 中无法找到发送端映射的 hue 值，直接报 `KeyError`。

**修复**：hue mapping 只能使用 `P_a ∩ P_b` 的公共探针，确保两个接收端都能观测到所有发送的 hue。

进一步发现 **模型不匹配 bug**：最初用公共探针重新提取指纹做 hue mapping，导致 mapping 基于 6-probe 模型，而实际解码器使用 8-probe 模型，legal BER 严重恶化。修复后改为用完整 `models_a` 的方向但限制可观测探针为公共子集。

### 9.4 实验结果（重叠度扫描）

固定 `P_a = [5, 40, 80, 155, 185, 265, 335, 365]`，改变 `P_b` 与 `P_a` 的公共探针数，测试位置 `(1, 3, 12, 22)`，非法位置 `Pos 2`：

| 公共探针数 | Legal mean secure BER | Illegal mean secure BER (individual) | Illegal joint secure BER |
|-----------|----------------------|--------------------------------------|--------------------------|
| 4 | **0.1562** | 0.3750 | **0.3750** |
| 5 | **0.1562** | 0.3750 | **0.3750** |
| 6 | **0.1875** | 0.3750 | **0.3750** |
| 7 | **0.0625** | 0.3750 | **0.3750** |
| 8 | **0.0156** | 0.3750 | **0.3750** |

*注：8 个公共探针意味着 `P_a = P_b`，此时双探针退化为单探针。*

### 9.5 结论

1. **零安全增益**：在所有重叠度下，联合 illegal secure BER 严格等于单探针 illegal secure BER（0.3750）。`P_a` 和 `P_b` 在非法位置产生的错误**完全相关**，联合判决没有任何额外惩罚效果。
2. **可靠性-安全性根本权衡**：
   - 公共探针少（4-5）：legal BER 高达 0.156，通信不可靠
   - 公共探针多（7-8）：legal BER 下降到 0.016-0.063，但 `P_a` 和 `P_b` 模型几乎相同，错误相关性趋近 1.0
3. **物理根源**：非法位置拥有全 360° 测量数据，无论用哪 8 个探针建模，SVD 第一主成分方向都高度相似（因共享同一 LED 阵列照明），导致不同探针子集的解码输出高度一致。

> **判断**：双探针联合解码**无法**使 4-位置安全通信达到目标（legal BER ≤ 0.005 且 illegal secure BER ≥ 0.2）。该路径在当前物理条件下不具备可行性。

## 十、人工噪声注入实验（Artificial Noise Injection）

### 10.1 动机
借鉴无线物理层安全中的经典思想（Goel & Negi）：在发送信号中注入与合法信道正交的人工噪声，使合法接收端不受影响，而非法接收端受干扰。

数学形式：
$$x = \sum_{i=1}^{4} b_i c_i + \alpha n, \quad \text{s.t.} \quad c_i^T n = 0$$

其中 $c_i$ 是位置指纹（code 向量），$b_i \in \{-1,+1\}$ 是发送比特，$n$ 是人工噪声向量，$\alpha$ 是噪声强度。

### 10.2 实现方法
- **单主成分模型**：回到 zero-BER 基线（位置 1,3,12,22，探针 `[5, 40, 80, 155, 185, 265, 335, 365]`）
- **噪声构造**：求解 $C^T n = 0$（$C \in \mathbb{R}^{8 \times 4}$），在4维零空间中随机采样并优化
- **发送端假设**：可同时调光多个 LED 角度，发送探针加权组合 $w_i = e_{h_i} + \alpha n$
- **观测模型**：每个 chip 的观测光谱 = $Y_{h_i} + \alpha \cdot Y_{\text{noise}}$，其中 $Y_{\text{noise}} = \sum_p n_p Y_p$

### 10.3 实验结果

| Alpha | Legal mean secure | Min illegal secure | Avg illegal secure |
|-------|------------------|-------------------|-------------------|
| 0.00  | **0.0000**       | 0.3438            | 0.3555            |
| 0.10  | **0.0000**       | 0.3438            | 0.3555            |
| 1.00  | **0.0000**       | 0.3438            | 0.3555            |
| 10.00 | **0.0000**       | 0.3438            | 0.3555            |
| 100.00| **0.0000**       | 0.3438            | 0.3555            |

**Legal BER 完全不受影响**：所有 alpha 下 secure BER = 0，说明噪声被合法位置完美抵消。

**Illegal BER 完全不变**：所有 alpha 下 min illegal secure BER 恒定在 0.3438，没有任何提升。

### 10.4 失败原因分析

1. **零空间向量与非法 code 也近乎正交**
   - $n$ 满足 $C^T n = 0$（与4个合法 code 正交）
   - 但由于所有28个位置的 SVD 第一主成分方向高度共享（correlation > 0.9），非法位置的 code 也位于由合法 code 张成的近似子空间中
   - 因此 $c_{\text{illegal}}^T n \approx 0$，噪声对非法位置同样无影响

2. **对称性陷阱**
   - 在当前物理条件下，所有位置的指纹向量都高度相似
   - 任何与合法集合正交的线性操作，也必然与非法集合近乎正交
   - 人工噪声的"方向性"无法区分合法和非法位置

### 10.5 结论

> **人工噪声注入方案在当前物理条件下完全无效。**
>
> 虽然合法位置确实不受噪声影响（legal BER = 0），但非法位置也不受影响（illegal BER 不变）。噪声的"正交性"对所有位置（合法和非法）一视同仁，无法创造安全区分。
>
> 这与多主成分、双探针方案失败的根源相同：**所有28个位置位于同一个低维指纹子空间，任何线性操作都无法在其中创造出独立的合法/非法区分维度。**
