# 当前实验方案总结

## 目标

当前实验围绕位置自生指纹通信中的探针调度安全性展开，目标是在保证合法位置可靠解码的前提下，提高非法位置窃听时的最小安全误码率 `min_secure_BER`，使其尽量接近 `0.5`。

核心安全指标为：

```text
secure_BER = min(BER, 1 - BER)
```

因此：

- `secure_BER = 0` 表示非法位置可以稳定正确或稳定反向解码，安全性最差。
- `secure_BER = 0.5` 表示非法位置接近随机猜测，安全性最好。

## 随机 Probe Hopping 方案

原始随机 hopping 策略为：

```python
selected_entries = [rng.choice(list(probe_pool)) for _ in bit_blocks_pm]
```

含义是：

- 每个 bit block 独立随机选择一个 probe set。
- 选择是有放回的均匀随机抽样。
- 不保证每个 probe set 使用次数相同。
- 不保证避免连续重复。
- 不根据非法位置风险做优化。

该方法简单，但安全性不一定最优，因为它没有利用每个 probe set 对不同非法链路的互补性。

## 离线探针调度方案

为避免在线优化影响通信速率，当前新增了离线 probe 调度方案。

新增脚本：

```text
E:\LuminaLink\Position_fingerprint_experiment\test-3\offline_probe_schedule_3pos.py
```

输出文件：

```text
E:\LuminaLink\Position_fingerprint_experiment\test-3\yellow_offline_probe_schedule_3pos.csv
```

流程如下：

1. 读取已有 probe pool。
2. 对每个合法位置组合，重建每个 probe set 的合法位置模型。
3. 离线评估每个 probe set 对所有非法位置和合法链路的 BER。
4. 求最优使用比例 `p_k`。
5. 根据比例生成长度为 `T` 的固定调度序列。
6. 对序列做风险均衡排序。
7. 在线通信时只按固定序列循环查表。

优化目标为：

```text
maximize_p min_{e,l} min(
    sum_k p_k BER_{e,l}(S_k),
    1 - sum_k p_k BER_{e,l}(S_k)
)
```

其中：

- `e` 表示非法位置。
- `l` 表示合法位置链路。
- `S_k` 表示第 `k` 个 probe set。
- `p_k` 表示第 `k` 个 probe set 的使用比例。

在线阶段只需要：

```python
probe_set_id = schedule_sequence[t % schedule_length]
```

因此在线阶段没有额外优化开销。

## 当前局限

当前离线调度的提升幅度可能不显著，主要原因是：

```text
调度优化只能在已有 probe pool 内重新分配使用比例，无法突破 probe pool 本身的安全上限。
```

如果当前 `K=5` 个 probe set 对某条弱非法链路的 secure BER 都较低，那么无论如何调度，该弱链路的 min BER 都难以接近 `0.5`。

因此，当前方案的瓶颈可能不在调度算法，而在 probe pool 的规模和安全互补性。

## 后续优化方向

建议后续优先改进 probe pool 构建阶段，而不是只优化调度阶段。

推荐方向：

1. 扩大 probe pool 大小

   当前通常为 `K=5`，建议提高到：

   ```text
   K = 20 ~ 50
   ```

   更大的 probe pool 能提供更多安全互补性。

2. 搜索阶段加入安全目标

   不只筛选合法 BER 为 0 的 probe set，还应优先选择：

   ```text
   min_secure_BER 高
   与已有 probe set 弱链路不同
   probe 重叠度低
   风险路线互补
   ```

3. 使用整数规划优化实际使用次数

   当前先优化连续比例 `p_k`，再映射到长度 `T` 的序列。更贴近实际的方式是直接优化整数使用次数 `n_k`：

   ```text
   maximize z
   subject to:
     sum_k n_k = T
     n_k integer
     z <= sum_k n_k * BER_{r,k} / T
     z <= 1 - sum_k n_k * BER_{r,k} / T
   ```

4. 引入密钥偏移或多序列

   在线阶段可以使用：

   ```python
   schedule_sequence[(t + offset(key)) % T]
   ```

   或者预生成多个离线序列，通过密钥选择序列编号，降低固定周期被攻击者利用的风险。

## 当前推荐实验路线

短期推荐：

```text
已有 K=5 probe pool -> 离线调度 -> 与随机 hopping 对比
```

中期推荐：

```text
安全感知搜索 K=20~50 probe pool -> 离线 max-min 调度 -> 固定序列安全性测试
```

长期推荐：

```text
安全互补 probe pool + 整数规划调度 + 密钥偏移循环序列
```
