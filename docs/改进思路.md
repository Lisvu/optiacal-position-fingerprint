选择一组 probes，使合法位置的指纹码稳定可区分，同时使任意非法位置的指纹响应与任意合法位置的有效解码模式低相关、不可预测。


## 定义一个 probe 分数：

score(p) =
合法位置间差异 / 非法位置与合法位置的相似度

例如对某个 probe p，你有所有位置的投影值 z_i(p)。

可以设计：

legal_separation(p) = 合法位置 z 值之间的最小距离
illegal_risk(p) = 非法位置 z 值与最近合法位置 z 值的相似程度
score(p) = legal_separation(p) / (illegal_risk(p) + ε)

更具体一点：

score(p) =
min_{a,b ∈ legal, a≠b} |z_a(p) - z_b(p)|
/
( max_{e ∈ illegal, l ∈ legal} similarity(z_e(p), z_l(p)) + ε )

然后优先选 score 高的 probes。


## 让最危险的非法设备也尽可能难解码。

所以目标应该是 max-min：

max_S  min_{e ∈ illegal, i ∈ legal} secure_BER(e, i | S)

约束：

BER_legal_i(S) ≤ δ

其中 δ 可以取 0 或很小的值。


## 随机 probe hopping

也就是每个 block 不固定使用同一组 probes，而是从一个密钥控制的 probe 池里随机选择：

block 1：使用 probes A
block 2：使用 probes C
block 3：使用 probes B
...

合法设备知道选择规则，非法设备不知道。

优点是：

非法设备难以长期积累稳定映射；
即使某些 probes 被非法位置偶然解码，也不能持续有效；
安全性不只依赖空间区分，还依赖时变随机性。
